## 3. Cressie-Read Family Density Analysis

### 3.1 Setup

Define the **Cressie-Read family**:
```
Φ_CR := {ψ_λ : λ ∈ ℝ}
where ψ_λ(x) := x^{λ+1}  for λ ∉ {0, -1}
      ψ_0(x)  := x × ln(x)        (L'Hopital limit at λ → 0)
      ψ_{-1}(x) := -ln(x)         (L'Hopital limit at λ → -1)
```

### 3.2 Convexity classification

Recall (from commit 1c5d717 § Lemma 2 + 8c80e40 + 8f0e34d):

```
ψ_λ convex for λ ∈ (-∞, -1] ∪ [0, +∞)
ψ_λ concave for λ ∈ [-1, 0]
ψ_0 = x × ln(x) convex (textbook)
ψ_{-1} = -ln(x) convex (textbook)
```

Define the **convex Cressie-Read family**:
```
Φ_CR^conv := {ψ_λ : λ ∈ (-∞, -1] ∪ [0, +∞)} ∪ {ψ_0, ψ_{-1}}
```

### 3.3 Stone-Weierstrass density argument (Lemma 7.3 proposed)

**Lemma 7.3 (proposed, NOT proven in this R&D)**:
On any compact interval [m, M] ⊂ ℝ_{>0}, the convex Cressie-Read family Φ_CR^conv is **dense (in sup-norm)** in the space of continuous convex functions C^conv([m, M]).

**Proof outline (sketch)**:

Step 1: x^p for p ∈ ℝ generates an algebra on [m, M] separating points (x ≠ y ⟹ x^p ≠ y^p for any p ≠ 0).

Step 2: By Stone-Weierstrass theorem (algebra version), the algebra generated by {x^p : p ∈ ℝ} is dense in C([m, M]) (uniform convergence).

Step 3: For convex restriction:
- Convex C^conv([m, M]) is closed subspace of C([m, M]) under sup-norm.
- The intersection of dense {x^p : p ∈ ℝ} algebra with C^conv is non-trivial but **needs strict density argument** for convex subspace.

Step 4: Approximation by convex {x^p : p ≥ 1 ∨ p ≤ 0}:
- For any continuous convex φ on [m, M], approximate by piecewise-linear convex functions (standard).
- Each piecewise-linear convex function approximated by convex {x^p}.
